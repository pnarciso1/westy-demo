Westy component vocabulary

Every token below is inherited from Modernist — the same red-on-white, Archivo, zero-radius system. This page adds only what Westy's screens need on top: a way to mark AI-authored content, status tags for bills and tasks, and the household-specific rows and tiles used everywhere else in the app. Two repos (demo and production) should build from this file and nothing else.

The Westy mark — distinguishing AI content

Anything Westy generates — a chat reply, a bill explanation, a suggested action — carries this exact treatment: an accent-tinted field, square corners, a sparkle mark and the small-caps “Westy” label. Nothing a person typed or a document contains ever gets this styling. It is one component, reused everywhere — never a one-off.
